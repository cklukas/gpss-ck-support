# GPSS/CK Support Site

This repository hosts the support website for **GPSS/CK** via GitHub Pages.

Site URL:

- https://cklukas.github.io/gpss-ck-support/

Privacy policy:

- https://cklukas.github.io/gpss-ck-support/privacy.html

## Publish

Pushing to the `main` branch deploys the site through the workflow in
`.github/workflows/pages.yml`. In the repository settings, **Pages > Source**
must be set to **GitHub Actions** (one-time setup).
